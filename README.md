# embedded-systems
A repository where I make mini-projects to learn embedded systems. Simulations are made in QEMU

---

To build development environment, use scripts in `sensor-project/scripts`
```
./toolchain_setup.sh
./bootloader_setup.sh
./busybox_setup.sh
./kernel_setup.sh
```

Stage and run the system
```
./staging.sh
./start_system.sh
```
